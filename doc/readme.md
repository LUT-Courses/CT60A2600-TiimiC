# Doxygen-ohje

Tämän projektin Doxygen-konfiguraatio on tiedostossa `doc/Doxyfile`.

## Dokumentaation generointi

Aja projektin juuresta:

```bash
doxygen doc/Doxyfile
```

Tai jos `makefile`:ssa on docs-target:

```bash
make docs
```

## Dokumentaation avaaminen

Generoinnin jälkeen avaa selaimessa:

`doc/html/index.html`
